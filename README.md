# G&D electro group

Portfolio web site for G&D electro group LTD. Check it [Live](https://plamenpik.github.io/GDelectrogroup/).

## Stack

- Eleventy (11ty) for static site generation
- Sass for styles compilation
- Concurrently for local dev workflow

## Development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

Build output is generated in `docs/`.
